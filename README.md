# Penicillium sp. C220 — Dead Sea Water Response

## Overview

This repository contains analysis scripts supporting a study of morphological, biochemical, and transcriptomic responses of the Dead Sea sediment-derived fungus *Penicillium* sp. C220 to Dead Sea Water (DSW).

The study integrates dry-biomass measurements, scanning electron microscopy (SEM), crude extracellular carbohydrate quantification, Oxford Nanopore RNA sequencing, and targeted RT-qPCR.

## Experimental design

RNA-seq, SEM, and biochemical validation focused on 0%, 10%, and 20% DSW. Three biological replicates per condition were used for RNA-seq and biochemical validation.

A broader DSW concentration series was examined for fungal biomass accumulation.

## Repository contents

The archived analysis package contains:

- SEM image-analysis scripts
- Extracellular carbohydrate analysis
- Dry-biomass analysis
- RNA-seq differential-expression and figure-generation scripts
- RT-qPCR analysis and visualization
- Publication-alignment notes and script provenance documentation

Both original historical scripts and selected publication-aligned revisions are retained for transparency.

## RNA-seq data availability

The Oxford Nanopore RNA-seq dataset is associated with NCBI Gene Expression Omnibus (GEO) accession **GSE353704**.

https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE353704

## Reproducibility

Scripts are provided to document the computational analyses and figure-generation procedures. Some historical scripts require local input files or environment-specific paths.

The archived scripts should not be interpreted as an independently verified end-to-end executable workflow. See the accompanying publication-alignment documentation for provenance and outstanding verification notes.

## Organism

*Penicillium* sp. C220, isolated from Dead Sea sediment.
